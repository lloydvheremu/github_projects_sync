GitHub Projects Sync

Keep Odoo project tasks in sync with GitHub issues

Link an Odoo project to a GitHub repository and its issues are imported as tasks by a scheduled job.

  • v1 (in progress): one-way sync of GitHub issues into Odoo project tasks, with a scheduled job.
  • v2: two-way sync, so changes to an Odoo task update the issue, plus webhooks for near-real-time updates.
  • Later: GitHub Projects boards.

Setup and development notes are in the README on GitHub.
